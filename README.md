# licenta
Tesla app care se ocupa de culegerea datelor de la masina, masina trimite datele pe un server acasa, iar acasa serverul le analizeaza si face un raport(maybe cu AI) care sa il inmaneze user-ului dupa fiecare traseu, sau la un numar stabilit de km(poate fi modificat). 
Reason: Safety score, advices, consum ridicat = condu mai lent, consum normal good job
Daca totul este okay add a safety streak in app, u can compare it with ur friends
Asa cum streak-ul aduce lumea inapoi pe aplicatii, asa poate sa faca lumea sa conduca safe.
